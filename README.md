# 🎓 Ryde Foundation Profile Card – 2023 & 2024 Batches

This project contains profile card pages designed for the Ryde Foundation's 2023 and 2024 batches. The original version was created for the 2023 batch, and has now been updated and improved to support the 2024 batch with a fresh design and updated content.

## 🔗 Live Previews

- [2023 Batch Profile Card](https://www.rydefoundation.in/profileCard23.html)  
- [2024 Batch Profile Card](https://www.rydefoundation.in/profileCard24.html)

---

## ✨ Features

- 🔹 Clean and modern UI design
- 🔹 Fully responsive across devices
- 🔹 Each profile includes:
  - Profile image
  - Full name
  - Role or designation
  - Social media links (optional)
- 🔹 Lightweight and fast-loading

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript** (for any interactivity or hover effects)

---

## 📌 Notes

- The 2024 version is a modified version of the 2023 design with layout tweaks and updated member profiles.
- Both versions are kept for reference and archival purposes.
